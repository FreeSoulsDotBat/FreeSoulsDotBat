- 🌎 International delivery: digital-commerce journeys for tier-1 telecom operators in the **US (T-Mobile), Canada (Telus) and Brazil (Vivo)**, plus web3 products (Solidity smart contracts, crypto payment gateway) for **UK clients**

- 🗣️ Portuguese (native) · English (fluent) · Russian (basic, in progress)
